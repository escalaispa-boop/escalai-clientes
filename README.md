## Como usar com Claude Design

1. Abra o Claude Design em claude.ai
2. Conecte este repositório GitHub
3. Na conversa, mencione o cliente: "Crie um feed para a Fornatta Pizzaria seguindo a identidade em `fornatta-pizzaria/brand.md`"
4. Anexe logo e fotos de produto do Google Drive

## Estrutura de cada pasta

```
[cliente]/
  brand.md     ← cores, tipografia, estilo, voz da marca
  assets.md    ← links de logo, Drive, fotos de produto
```
